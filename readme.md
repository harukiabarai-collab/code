# 🎓 EDU401 CAI: นวัตกรรมสื่อความจริงเสริมเพื่อการศึกษา

ระบบคอร์สแวร์ (Computer-Assisted Instruction: CAI) บนเว็บแอปพลิเคชัน สำหรับรายวิชา EDU401 นวัตกรรมสื่อความจริงเสริมเพื่อการศึกษา พัฒนาขึ้นเพื่อใช้งานกับนักศึกษาคณะครุศาสตร์ โดยมีระบบหลังบ้าน (Backend) ที่จัดการด้วย **Supabase** อย่างเต็มรูปแบบ

## 🌟 จุดเด่นของระบบ (Features)

### 🧑‍🎓 สำหรับผู้เรียน (Students)
* **ระบบสมัครสมาชิกด้วยรหัสนักศึกษา:** ผูกบัญชีกับฐานข้อมูลรายชื่อโดยอัตโนมัติ (ใช้โดเมน `@edu.fakeuni.ac.th`)
* **แบบทดสอบก่อนเรียน/หลังเรียน (Pre-test / Post-test):** ระบบสุ่มข้อสอบคู่ขนานชุด A และ B (ตามรหัสคู่/คี่) 
* **บทเรียน 5 หน่วยการเรียนรู้:** พร้อมคำถามทบทวนความรู้ระหว่างเรียน (Formative Assessment) ที่ต้องตอบถูกจึงจะผ่าน
* **การจำลอง WebAR:** ทดลองใช้งานความจริงเสริมผ่านแท็ก `<model-viewer>` บนเบราว์เซอร์
* **ระบบส่งงานปฏิบัติ:** อัปโหลดไฟล์ (รูปภาพ/วิดีโอ/PDF) หรือส่งลิงก์ผลงาน พร้อมดูคะแนนและข้อเสนอแนะจากผู้สอน
* **สรุปผลการเรียน:** คำนวณคะแนนและค่าพัฒนาการ (Normalized Gain) อัตโนมัติ

### 👩‍🏫 สำหรับผู้สอน (Teachers)
* **Dashboard ติดตามความก้าวหน้า:** ดูข้อมูลนักศึกษาแบบเรียลไทม์ (คะแนน, หน่วยที่เรียนจบ)
* **ระบบตรวจงาน:** ดูไฟล์/ลิงก์ผลงานของนักศึกษา พร้อมให้คะแนนและพิมพ์ข้อเสนอแนะ
* **จัดการสื่อการเรียน:** อัปโหลดไฟล์เอกสาร (PDF, PPTX, DOCX) หรือเพิ่มลิงก์วิดีโอให้นักศึกษาศึกษาเพิ่มเติม
* **Export CSV:** ดาวน์โหลดสรุปผลการเรียนทั้งหมดไปใช้งานต่อใน Excel (รองรับภาษาไทย)

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

* **Frontend:** HTML5, CSS3, Vanilla JavaScript (Single Page Application ในไฟล์เดียว)
* **3D & AR:** `<model-viewer>` v3.4.0 (Google) สำหรับแสดงผล 3D และ WebXR
* **Backend:** [Supabase](https://supabase.com/)
  * **Auth:** จัดการระบบล็อกอินและตรวจสอบสิทธิ์
  * **Database:** PostgreSQL พร้อม Row Level Security (RLS) เพื่อความปลอดภัยขั้นสูงสุด
  * **Storage:** Private Buckets สำหรับเก็บรูปโปรไฟล์, ไฟล์ส่งงาน, และสื่อการสอน (เปิดผ่าน Signed URL)

## 🚀 คู่มือการติดตั้งระบบ (Installation Guide)

### ส่วนที่ 1: การเตรียมฐานข้อมูลบน Supabase
1. ไปที่ [Supabase](https://supabase.com) สมัครสมาชิกและสร้างโปรเจกต์ใหม่
2. ไปที่เมนู **Authentication > Providers > Email** 
   * ปิดสวิตช์ `Confirm email`
   * ปิดสวิตช์ `Secure email change`
3. ไปที่เมนู **SQL Editor** กด `+ New query` 
4. คัดลอกโค้ดทั้งหมดจากไฟล์ `setup.sql` ไปวาง แล้วกดปุ่ม **Run**
5. ตรวจสอบว่าตาราง (Tables), ฟังก์ชัน (Functions), และ Storage Buckets ถูกสร้างเรียบร้อยแล้ว

### ส่วนที่ 2: การจัดการผู้ใช้ (รายชื่อผู้เรียน & ผู้สอน)
1. **นำเข้ารายชื่อนักศึกษา:** 
   * ไปที่ **Table Editor** > เลือกตาราง `students`
   * กด `Insert` > `Import data via spreadsheet` เพื่ออัปโหลดไฟล์ CSV รายชื่อจริง (คอลัมน์: `id`, `title`, `first_name`, `last_name`, `section`)
2. **สร้างบัญชีผู้สอน:**
   * ไปที่ **Authentication > Users** กด `Add user` ใส่อีเมลของคุณ (ห้ามขึ้นต้นด้วยตัวเลข 11 ตัว) และตั้งรหัสผ่าน
   * กลับไปที่ **SQL Editor** รันคำสั่งนี้เพื่อตั้งค่าให้บัญชีของคุณเป็นผู้สอน:
     ```sql
     INSERT INTO public.teachers (user_id) 
     SELECT id FROM auth.users WHERE email = 'ใส่อีเมลผู้สอนของคุณที่นี่';
     ```

### ส่วนที่ 3: การเชื่อมต่อ Frontend
1. ไปที่เมนู **Project Settings** (รูปฟันเฟือง) > **API**
2. คัดลอกค่า `Project URL` และ `anon public key`
3. เปิดไฟล์ `courseware.html` ด้วย Text Editor ค้นหาตัวแปรส่วนหัวและวางค่าที่คัดลอกมา:
   ```javascript
   const SUPABASE_URL = 'https://YOUR_PROJECT_ID.supabase.co'; 
   const SUPABASE_ANON_KEY = 'YOUR_ANON_KEY';
   ```
4. นำไฟล์ `courseware.html` ไปอัปโหลดขึ้น Web Hosting (เช่น GitHub Pages, Netlify หรือ LMS ของสถาบัน)

## 🔒 ความปลอดภัย (Security)
* โค้ด HTML ใช้เฉพาะ `anon_key` ซึ่งปลอดภัยในการเปิดเผยต่อสาธารณะ
* ฐานข้อมูลเปิดการใช้งาน Row Level Security (RLS) ครบทุกตาราง ผู้เรียนไม่สามารถอ่านข้อมูลของผู้อื่น, ไม่สามารถแก้คะแนนตัวเองได้, และไม่สามารถลบสื่อของผู้สอนได้
* Storage Buckets ทั้ง 3 แห่งถูกตั้งเป็น `Private` (เข้าถึงผ่าน Signed URL ชั่วคราวเท่านั้น) และถูกจำกัดขนาด/ประเภทไฟล์ไว้ล่วงหน้าผ่าน SQL
